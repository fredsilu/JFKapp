SUPPORT & TROUBLESHOOTING
================================================================================

If Analytics Page Won't Load:
  1. Check Firebase connection
  2. Verify Firestore is accessible
  3. Check browser/app console for errors
  4. Restart dev server

If Charts Don't Render:
  1. Verify react-native-chart-kit installed
  2. Check data is not empty
  3. Review console for chart errors
  4. Check data format matches expected

If Data Not Updating:
  1. Check internet connection
  2. Verify Firestore permissions
  3. Check data is being saved to Firestore
  4. Refresh page/restart app
