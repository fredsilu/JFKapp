# JFKApp 🍽️

JFKApp est une application **Expo / React Native** de gestion de restaurant
permettant de gérer **clients, plats, ingrédients, commandes** et
d’afficher des **analytics en temps réel** via Firebase.

L’application fonctionne sur **Android, iOS et Web** et utilise une
architecture claire orientée services et types TypeScript.

---

## 🚀 Démarrage rapide

### Prérequis
- Node.js (recommandé : v18+)
- npm ou yarn
- Expo (via `npx`, aucun install global requis)

### Installation
```bash
npm install
