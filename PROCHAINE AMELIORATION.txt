J'ai créé un module utilitaire costs.ts qui contient toutes les fonctions nécessaires pour :

Calculer le coût des ingrédients d'un plat
Calculer le coût total d'un plat avec marge
Calculer le coût des ingrédients supplémentaires
Calculer le coût total d'une commande
Calculer la marge bénéficiaire
Formater les montants en euros
Ces fonctions peuvent maintenant être utilisées dans les composants DishDetails, OrderDetails et partout où nous avons besoin de calculer des coûts.

Pour utiliser ces fonctions, il suffit de les importer :


import { 
  calculateDishTotalCost, 
  calculateOrderTotalCost,
  formatCurrency 
} from '@/src/utils/costs';
Par exemple dans OrderDetails :


const totalCost = calculateOrderTotalCost(order);
const profit = calculateOrderProfit(order);

// Affichage
<Text>Total : {formatCurrency(totalCost)}</Text>
<Text>Marge : {formatCurrency(profit)}</Text>
Les avantages de cette approche sont :

Centralisation des calculs
Cohérence des calculs dans toute l'application
Facilité de maintenance
Possibilité d'ajuster la marge globalement
Format monétaire uniforme
